# Sea of Grass

Source for [seaofgrass.studio](https://seaofgrass.studio).

Hand-coded static site. Served by GitHub Pages from the `main` branch;
the `CNAME` file binds the custom domain.

## Local preview

Open `index.html` directly, or serve the folder:

    python3 -m http.server 8000

## Deploying

Push to `main` — GitHub Pages rebuilds automatically.
